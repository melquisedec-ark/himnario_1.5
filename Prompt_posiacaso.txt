### 2. BASE DE DATOS (Estructura SQL Actual)
Tablas creadas y funcionales:
CREATE TABLE himnos (
    id INT AUTO_INCREMENT PRIMARY KEY,
    numero INT NOT NULL UNIQUE,
    titulo VARCHAR(255) NOT NULL,
    creado_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE estrofas (
    id INT AUTO_INCREMENT PRIMARY KEY,
    himno_id INT NOT NULL,
    tipo ENUM('verso', 'coro', 'puente') NOT NULL DEFAULT 'verso',
    orden INT NOT NULL,
    contenido TEXT NOT NULL,
    FOREIGN KEY (himno_id) REFERENCES himnos(id) ON DELETE CASCADE
);

### 4. LÓGICA CLAVE DEL VISOR (presentacion.php)
El archivo `presentacion.php` es el más avanzado. Su estado actual incluye:
- Carga de datos: PHP inyecta el array de estrofas en JS mediante `json_encode`.
- Navegación: JS maneja el cambio de diapositivas (Next/Prev) sin recargar página.
- Diseño: Fondo negro, texto blanco centrado. Usa `line-height: 1.15` y `text-shadow` para legibilidad.
- Panel de Configuración: Un menú desplegable (⚙️) que permite cambiar en tiempo real:
  1. Tamaño de letra (Variable CSS --font-scale multiplicando a --base-size).
  2. Color de Fondo y Color de Texto.
  3. Persistencia: Usa `localStorage` para recordar la configuración del usuario.
- Correcciones aplicadas: El título del himno es visible (position absolute), y el tamaño de letra tiene un tope (max 1.6) para evitar desbordamiento vertical.
